# Deep Learning-Based Poverty Mapping Using Satellite Imagery

## 🌍 Project Overview

Poverty mapping is important for understanding the development conditions of different regions. Traditional methods often depend on surveys and census data, which can take significant time and resources to collect.

This project explores how satellite imagery and deep learning can be used to identify visual patterns associated with different levels of poverty. A Convolutional Neural Network (CNN) is used to analyse satellite images and classify areas based on poverty-related patterns.

## 🎯 Objective

The main objective of this project is to explore the use of deep learning and satellite imagery for poverty mapping.

The project aims to:

- Analyse satellite images using deep learning
- Identify visual patterns associated with different poverty levels
- Build a CNN-based image classification model
- Evaluate the model's classification performance
- Explore how satellite imagery can support poverty-related analysis

## 📊 Dataset

The project uses the **Bolivia Satellite Images Dataset** from Kaggle.

The dataset contains satellite images representing different geographical areas in Bolivia.

**Dataset:**  
Kaggle – Bolivia Satellite Images Dataset

- Python
- TensorFlow / Keras
- Convolutional Neural Network (CNN)
- NumPy

- Google Colab / Jupyter Notebook

## 🧠 Methodology

The project follows these main steps:

1. Collect and organise the satellite image dataset
2. Preprocess and resize the images
3. Prepare the data for model training
4. Split the dataset into training and validation sets
5. Build a CNN-based deep learning model
6. Train the model using the satellite images
7. Evaluate the model using classification metrics
8. Analyse the model's predictions

## 🔬 CNN Approach

A Convolutional Neural Network is used because CNNs are well suited for analysing images.

The model learns visual features from satellite images through convolution and pooling layers and uses these learned features to classify the images according to the target categories.

## 📈 Expected Outcome

The project demonstrates how deep learning can be applied to satellite imagery to identify patterns related to poverty levels.

It also provides practical experience in image preprocessing, CNN model development, model evaluation and computer vision.

## 🚀 Future Scope

The project can be extended by:

- Using larger and more diverse satellite image datasets
- Improving model performance through hyperparameter tuning
- Exploring transfer learning with pretrained CNN architectures
- Combining satellite imagery with socioeconomic and geographic data
- Developing a more detailed geographical poverty-mapping system

## 🌍 Project Overview

## 🧠 Why CNN?

A Convolutional Neural Network is suitable for this project because CNNs are designed to learn visual features from images.

The convolutional layers learn important patterns from the satellite images, while pooling layers help reduce the spatial dimensions and retain relevant features. The extracted features are then used by the network for classification.
